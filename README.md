# Tendências em IA — Engenharia de Prompt (tendencias_ai)

Este repositório reúne materiais, atividades e planos de aula do curso "Tendências em Inteligência Artificial" (Engenharia de Prompt) ministrado pela Profa. Kadidja em 2026/2. O README usa o modelo 5W para apresentar de forma direta os objetivos do plano de aulas e orientar estudantes e colaboradores.

---

## 5W (Quem / O quê / Quando / Onde / Por quê)

- Quem (Who)
  - Público-alvo: estudantes de graduação e pós-graduação interessados em tendências de IA e em prática de engenharia de prompt.
  - Responsável pelo curso: Profª Kadidja (kadidja.oliveira@udf.edu.br).
  - Contribuidores: alunos do curso, monitores e colaboradores externos.

- O quê (What)
  - Conteúdo: plano de aulas, atividades, materiais de apoio, exemplos de prompts, estudos de caso e avaliações.
  - Objetivos de aprendizagem (resumidos do plano de aulas):
    1. Entender conceitos e tendências atuais em IA aplicáveis a ensino e pesquisa.
    2. Aprender boas práticas de engenharia de prompts para LLMs (Large Language Models).
    3. Desenvolver, testar e iterar prompts para tarefas específicas (exploração, geração, avaliação).
    4. Aplicar princípios éticos e de responsabilidade no uso de IA e prompts.
    5. Produzir entregáveis práticos: relatórios, notebooks e pequenos projetos aplicados.

- Quando (When)
  - Semestre: 2026/2 (conforme plano de aulas).
  - Cronograma: cada Unidade (ex.: Unidade_01) contém atividades e prazos — consulte os arquivos dentro de cada pasta para datas e instruções específicas.

- Onde (Where)
  - Local: materiais centralizados neste repositório GitHub (https://github.com/sztsu/tendencias_ai).
  - Ambiente prático: notebooks, execução local ou em ambientes de nuvem (Google Colab, Binder, etc.) quando indicado nas atividades.

- Por quê (Why)
  - Justificativa: preparar estudantes para trabalhar com modelos de linguagem e outras técnicas de IA, capacitando-os a formular prompts eficazes, interpretar saídas, avaliar resultados e considerar impactos sociais e éticos.
  - Benefício: habilidades práticas transferíveis para pesquisa, indústria e docência.

---

## Como usar este repositório (How)

1. Navegue pelas unidades: cada pasta Unidade_0X contém o plano da unidade, atividades e materiais.
2. Leia o arquivo do plano de aulas (ex.: PlanodeAulas_...) para conhecer objetivos, critérios de avaliação e cronograma.
3. Execute notebooks e exercícios sugeridos; siga instruções de cada atividade (prazos e formato de entrega estão nas pastas correspondentes).
4. Faça um fork / clone para trabalhar localmente. Abra PRs para contribuir com melhorias nos materiais.

Exemplo de comandos:

```bash
# clonar o repositório
git clone https://github.com/sztsu/tendencias_ai.git
cd tendencias_ai
# abrir um notebook (exemplo usando Jupyter)
jupyter notebook
```
